# 路线图

## 已经做了

- **v0.1 骨架**：左栏入口 + 中央面板 + 模块契约 + 中英文案 + 构建与 CI。面板目前是空状态。

## 待定（还没有决定）

内容方向没定，下面是候选，不是承诺：

- 街机小游戏（2048、贪吃蛇等），纯前端、零 token；
- 摸鱼电台 + 番茄钟：WebAudio 程序化生成，不引外部音源；
- 让 agent 陪你玩一局：agent 出题、当庄家或点评；**每次交互都烧 token**，要按需触发；
- 成就墙：用真实会话数据解锁成就，依赖宿主提供的会话接口。

挑方向的判断标准：先在 DSH 里真用一周，看哪个是等 agent 时真会点开的。

## 明确不做

- 联网排行榜、账号体系、任何后端服务；
- 第三方素材、字体、UI 组件库；
- 自动弹窗或打断当前会话；
- 把游戏内容塞进模型上下文。

## 骨架之后的第一步

选一个模块，照 [modules.md](./modules.md) 走通一次完整流程；跑通一次之后，第二个模块就只是复制粘贴。
